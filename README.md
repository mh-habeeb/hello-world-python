# Hello World in Python

A small first project as I build my Python foundations for data science and AI/ML.

## What it does

- Asks for your name.
- Removes extra spaces around the input.
- Uses `world` if you press Enter without typing a name.
- Prints a friendly greeting.

## Run it

You need Python 3.6 or newer. No extra packages are required.

```bash
python main.py
```

On Windows, you can also run `py main.py`.

## Example

```text
What is your name? Habeeb
Hello, Habeeb! Welcome to my first Python project.
```

Press Enter at the name prompt to see the default greeting.
